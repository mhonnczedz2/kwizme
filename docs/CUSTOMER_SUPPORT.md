## Before Contacting Support

To help us assist you faster, please check:

### 📋 Quick Troubleshooting
1. **Refresh** your browser page
2. **Clear** browser cache and cookies
3. **Try** a different browser (Chrome, Firefox, Safari)
4. **Check** your internet connection
5. **Review** our FAQ at /support

### 📁 File Issues Checklist
- ✅ File is under 10MB
- ✅ File format is supported (PDF, DOCX, PPTX, TXT)
- ✅ File contains readable text content
- ✅ File is not password protected

### 🔐 Account Issues Checklist
- ✅ Using the correct email address
- ✅ Password is entered correctly (check Caps Lock)
- ✅ Checked spam folder for verification emails
- ✅ Tried password reset if needed

If your issue isn't resolved satisfactorily:

1. **Reply** to your existing support email
2. **Mark** subject line with "ESCALATION REQUESTED"
3. **Explain** why the current solution isn't working
4. **Provide** any additional relevant information

Escalated issues receive priority attention and senior team review.
