This document contains standardized response templates for KwizMe customer support to ensure consistent, helpful, and professional communication.

## General Guidelines

- Always use a friendly, professional tone
- Acknowledge the user's issue clearly
- Provide actionable solutions when possible
- Include relevant links to help documentation
- Sign with your name and KwizMe Support signature
- Response time goal: Within 24 hours (business days)

## Technical Issues

### Template: Quiz Generation Problems

**Subject**: Re: Quiz Generation Issue

Hi [Name],

Thanks for reaching out about the quiz generation issue. Let's get this sorted out for you!

**Troubleshooting Steps:**
Please try these steps in order:

1. **File Check**: Ensure your file is under 10MB and contains readable text
2. **Refresh**: Refresh your browser and try uploading again
3. **Different File**: Try with a different document to isolate the issue
4. **Browser**: Try a different browser (Chrome, Firefox, Safari, or Edge)
5. **Clear Cache**: Clear your browser cache and cookies

**File Requirements:**
- Supported formats: PDF, Word (.docx), PowerPoint (.pptx), Text (.txt)
- Maximum size: 10MB per file
- Must contain readable text content

**Still Having Issues?**
If none of these steps work, please reply with:
- Your browser and version
- File type and approximate size
- Error message (if any)
- Screenshots (if helpful)

We're here to help!

[Email Signature]

### Template: Account Issues

**Subject**: Re: Account Issue

Hi [Name],

Thank you for contacting us about your account issue. We're here to help!

**For Password Reset:**
1. Go to https://kwizme-app.vercel.app/auth/login
2. Click "Forgot Password"
3. Enter your email address
4. Check your email (and spam folder) for the reset link
5. Follow the link to set a new password

**For Login Problems:**
- Ensure you're using the correct email address
- Check that Caps Lock is off
- Try clearing your browser cache
- Use an incognito/private browser window

**For Data Recovery:**
If you had quizzes saved before creating an account, they may be stored locally. Creating an account doesn't automatically transfer anonymous data.

**Need More Help?**
Please provide details about:
- The specific error message you're seeing
- What steps you've already tried
- Your browser and device type

[Email Signature]

## Escalation Guidelines

### When to Escalate:
- Critical bugs affecting multiple users
- Security or privacy concerns
- Legal or compliance issues
- Requests for features requiring significant development
- Angry or dissatisfied users after initial resolution attempt

### Escalation Process:
1. Mark email as "ESCALATED"
2. Include summary of issue and previous correspondence
3. CC development team lead if technical issue
4. Response time: Within 4 hours for escalated issues
